
# Personal Portfolio — Project 04

## About the Project

This is my personal portfolio website.
It introduces me, presents my skills and projects,
and provides a way to contact me.

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6
- Git and GitHub

## Website Sections

- Home
- About Me
- Skills
- Projects 00–03
- Hobbies
- Contact Form
- Footer

## Features

- Pink and white design
- Dark Mode and Light Mode switcher
- Responsive layout for mobile and desktop
- Interactive contact form demo
- GitHub links to my projects

## How to Run

1. Open the project folder.
2. Open index.html in a web browser.
